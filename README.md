
# Projeto integrador | Senac

**Uma plataforma digital para conectar, apresentar e valorizar os projetos desenvolvidos pela turma do curso Programador Full Stack do Senac.**

## Contexto acadêmico

. Instituição: Senac
. Curso: Programador Full Stack
. Projeto: Projeto Integrador (PI)

### 1 Sobre o projeto

*O PI (Projeto Integrador) é uma plataforma web acadêmica desenvolvida como parte do curso de Programador Full Stack do Senac-Seabra.*

O projeto tem como propósito centralizar, organizar e apresentar os projetos desenvolvidos pelos alunos, funcionando como um portfólio digital coletivo. A plataforma oferece um espaço para explorar diferentes ideias, soluções e aplicações criadas durante a formação, valorizando o aprendizado, a criatividade e as habilidades técnicas da turma.

Mais do que reunir trabalhos acadêmicos, o PI busca representar a identidade coletiva dos estudantes e demonstrar, na prática, os conhecimentos adquiridos ao longo do curso.

### 2 Objetivos

. Centralizar os projetos desenvolvidos pelos integrantes da turma.
. Apresentar os trabalhos de maneira organizada e intuitiva.
. Valorizar a criatividade e o desenvolvimento técnico dos estudantes.
. Criar um ambiente digital de apresentação e exploração de projetos.
. Demonstrar a aplicação prática dos conhecimentos de desenvolvimento web.
. Construir uma identidade visual própria para representar a turma.

### 4 Arquitetura e evolução

*O PI foi criado com possibilidade de evolução para uma aplicação Full Stack.*

Proposta de expansão:

- Backend para processamento e gerenciamento de informações.
- Banco de dados para armazenamento de projetos e usuários.
- Sistema de autenticação.
- Cadastro e gerenciamento de projetos.
- Diferenciação de permissões entre usuários.
- Integração entre frontend, backend e banco de dados.

**Esses recursos representam *possibilidades de evolução arquitetural* e não devem ser confundidos com funcionalidades já implementadas na versão atual.**

### 5 Status do projeto

O projeto encontra-se em desenvolvimento, com sua interface principal estruturada em HTML, CSS e JavaScript.

A evolução da plataforma contempla aprimoramentos visuais, expansão das funcionalidades e a possibilidade de implementação de uma arquitetura Full Stack.
